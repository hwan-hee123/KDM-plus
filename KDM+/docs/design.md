# 장비 중심 리디자인

적용 스킬: https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md

## 방향

KDM의 공용 장비 선반을 웹으로 옮긴다. 홍보 문구보다 장비를 고르고 기간을 입력하는 작업을 우선한다.

- 색: 흰색 #FFFFFF, 검정 #000000, 사진 바탕 #F3F4F5, 본문 #333333, 보조 글자 #686C72, 구분선 #E0E2E5. 초록은 대여 가능 상태에만 사용.
- 글꼴: 로컬 Pretendard Variable. 한국어 제목 48–64px, 본문 15px, 상태 12px. 과도한 자간과 영문 장식 라벨 배제.
- 배치: 왼쪽 정렬. 상단에는 사이트명과 이용 안내, 그 아래 짧은 제목/설명. 검색·카테고리 바로 아래 3열 장비 선반. 모바일은 2열.
- 초점: 제품 사진 한 가지에 시각적 비중을 둔다. 그림자/그라데이션/장식 번호는 쓰지 않음.

```text
KDM+                                      이용 안내
장비를 고르고,                  19대의 공용 장비
작업을 시작하세요.              대여 안내
[검색________________________________________]
전체 / 노트북 / 아이패드 / 아이맥 / 카메라 / 캠코더
[ 장비 사진 ] [ 장비 사진 ] [ 장비 사진 ]
  이름 + 번호 + 상태 / 신청하기
```

초기 안의 사진 배너/통계 띠/장식 화살표는 장비 탐색을 늦추므로 제거. 같은 종류가 한 줄을 점유하지 않도록 첫 장비부터 종류별로 섞어서 제시.

## 신청 창

데스크톱: 장비 요약 옆에 달력/입력 양식. 모바일: 장비 요약 아래에 달력과 양식이 쌓이는 한 열. 날짜 숫자로 기간 선택, 이름과 기수는 빈칸, 사용 목적은 선택. 실제 서버 접수와 구분하는 미리보기 단계.
